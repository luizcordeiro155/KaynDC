## Sobre o Kayn

O **Kayn** é um projeto para comunidades do Discord que reúne entretenimento, cards, economia, música, inteligência artificial, universo gamer, moderação e ferramentas de gerenciamento.

Este é o repositório público de apresentação do projeto. Os repositórios **KaynApp** e **KaynOficial** permanecem privados e o código-fonte não é distribuído aqui.

- 🎴 Cards, coleção, inventário e economia
